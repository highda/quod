---
name: ledger
description: Record a toolbox, prompt, doctrine, bug or infra deficiency for humans to act on between runs. Use instead of working around a problem silently.
---
`quod ledger add <tool|prompt|doctrine|bug|infra|library> --title "<short>" --rationale "<what is missing and what it cost you>" --evidence "<claim/branch/artifact ids>" -b <branch>`
Then continue with the best available tool. Never install or pin anything mid-run.
